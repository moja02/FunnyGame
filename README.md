# FunnyGame ⚡🎮

منصة ألعاب التحدي وسرعة البديهة والذكاء الجماعية، تعمل مباشرة كـ **Web App / PWA** بأعلى أداء على متصفحات الهواتف الذكية (iOS Safari / Android Chrome) والكمبيوتر دون الحاجة لأي تنزيل أو متجر تطبيقات.

---

## 🌟 مميزات المنصة (Features)

### 1. الشاشة الرئيسية والواجهة الأركيد
- تصميم متجاوب داكن عصري مستوحى من ألعاب الأركيد الحديثة.
- **الأزرار الرئيسية الثلاثة:**
  - 🕹️ **الدخول للألعاب:** شبكة كروت مربعة (1:1) تعرض الألعاب المتوفرة والقادمة.
  - ⚙️ **الإعدادات:** التحكم في المؤثرات الصوتية (SFX)، الموسيقى، والاهتزاز اللمسي (Haptics).
  - 📖 **التعليمات:** شرح قواعد وأهداف كل لعبة بالتفصيل.

### 2. لعبة الفارق الزمني (Time Duel) ⏱️
- **تحدي شخصين (نفس الجوال):** شاشة مقسومة وانقلاب 180 درجة (180° Inverted) ليجلس اللاعبان وجهاً لوجه على نفس الشاشة.
- **تدريب فردي ضد الروبوت:** 3 مستويات صعوبة (سهل، متوسط، مستحيل).
- **مؤقت التحدي المخفي:** يختفي العداد بعد 1.5 ثانية (`?.?? ث`) للاعتماد على التقدير الذهني الدقيق.
- **نظام المباريات والتتويج:** احتساب النقاط (Best of 3) واحتفال الفوز مع القصاصات الملونة (Confetti).

### 3. دعم كامل لتطبيقات الويب التقدمية (PWA)
- تثبيت بضغطة زر عبر خيار **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** على هواتف iPhone و Android.
- تشغيل أوفلاين وسرعة تحميل فائقة بواسطة **Service Worker**.
- محرك صوتي اصطناعي مدمج (**Web Audio API Synthesizer**) بدون الحاجة لتحميل ملفات صوتية خارجية.
