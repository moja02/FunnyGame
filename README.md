# FunnyGame 🎮

لعبة أجهزة ذكية جماعية تفاعلية تركز على سرعة البديهة، الذكاء والتركيز، مبنية باستخدام **Flutter** و **Flame** وفق مبادئ **Clean Architecture** ونظام التحديثات الهوائية السريعة (**OTA Patching**).

---

## 🌟 محتويات المشروع (Features)

### 1. الشاشة الرئيسية والواجهة
- **شعار اللعبة (FunnyGame)**: تصميم أنيق وعصري مع رسوميات متحركة.
- **الأزرار الرئيسية الثلاثة**:
  - 🕹️ **الدخول للألعاب**: شبكة كروت مربعة (1:1) تعرض الألعاب المتوفرة والقادمة.
  - ⚙️ **الإعدادات**: التحكم في مستوى المؤثرات الصوتية (SFX)، الموسيقى، وتفعيل/إيقاف الاهتزاز (Haptics).
  - 📖 **التعليمات**: شرح تفصيلي لقواعد كل لعبة وطريقة لعبها.

### 2. الألعاب المتوفرة
- ⏱️ **لعبة الفارق الزمني (Time Duel)**:
  - تحدي بين لاعبين (شاشة مقسومة 180 درجة ليجلس اللاعبان وجهاً لوجه) أو لاعب ضد الذكاء الاصطناعي (Bot) بثلاث مستويات صعوبة (سهل، متوسط، محترف).
  - إيقاف المؤقت بأقرب جزء من الثانية للهدف المحدد مع إخفاء العداد (`?.??`) لزيادة الإثارة والتركيز.
  - نظام نقاط ومباريات (Best of 3).

### 3. بنية المشروع وهندسة البرمجيات (Clean Architecture)
```
lib/
├── core/                       # الطبقة المشتركة للخدمات الأساسية
│   ├── errors/                 # استثناءات وإخفاقات مخصصة (Failures & Exceptions)
│   ├── network/                # عميل الشبكة (Dio) مع دعم Resumable Downloads
│   ├── security/               # التحقق من سلامة الحزم المشفرة (SHA-256 Checksum)
│   └── storage/                # إدارة مسارات التخزين والتبديل الذري (Atomic Swap)
├── features/
│   ├── game/                   # لعبة الفارق الزمني (منطق منفصل + واجهات)
│   │   ├── domain/             # TimeDuelLogic (مستقل تماماً بدون UI)
│   │   └── presentation/       # TimeDuelScreen (واجهة تفاعلية 2-Player)
│   ├── menu/                   # القائمة الرئيسية والإعدادات وشبكة الألعاب
│   └── patch_manager/          # نظام التحديثات الهوائية التلقائية (OTA)
│       ├── data/               # نماذج ومستودع التحميل
│       ├── domain/             # PatchManifest & UpdateStatus
│       └── presentation/       # شاشة البداية وفحص التحديثات
└── main.dart                   # نقطة الانطلاق الرئيسية
```

### 4. نظام التحديثات الهوائي التلقائي (OTA Engine)
- فحص ملف الـ Manifest عبر الإنترنت.
- تحميل الحزم بنظام الاستئناف (Resumable Range Requests).
- فحص البصمة الرقمية (SHA-256) للتأكد من سلامة الملفات ومنع التلاعب.
- استبدال الملفات بالطريقة الذرية (Atomic Swap).

## 🚀 التشغيل والتطوير (Getting Started)

### المتطلبات
- Flutter SDK (3.x أو أحدث)
- Dart SDK
- Android SDK / NDK (لبناء نسخة الأندرويد)

### خطوات التشغيل
1. **تثبيت الحزم:**
   ```bash
   flutter pub get
   ```

2. **تشغيل الفحوصات (Tests):**
   ```bash
   flutter test
   ```

3. **تشغيل اللعبة على المتصفح (Web):**
   ```bash
   flutter run -d chrome
   ```

4. **بناء نسخة الهاتف (Android APK):**
   ```bash
   flutter build apk --debug
   ```
